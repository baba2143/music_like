## 1. 概要

### 1.1. タスク管理方針
- **スプリント**: 2週間単位
- **優先度**: 高（H）/ 中（M）/ 低（L）
- **見積もり**: 人日（PD = Person Days）
- **ステータス**: 未着手 / 進行中 / 完了 / ブロック

### 1.2. チーム構成（想定）
- フロントエンドエンジニア（FE）: 2名
- バックエンドエンジニア（BE）: 1名
- UI/UXデザイナー（UI）: 1名
- プロダクトマネージャー（PM）: 1名
