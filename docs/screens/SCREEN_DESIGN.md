## 1. 概要

### 1.1. 設計方針
- **SNS型UI**: フィード中心の設計
- **直感的操作**: タップ・スワイプで操作完結
- **視覚的魅力**: 音楽コンテンツを美しく表示
- **アクセシビリティ**: スクリーンリーダー対応、色覚特性配慮

### 1.2. デザインシステム

**カラーパレット**:
```
プライマリカラー: #FF4081（ピンク）
セカンダリカラー: #3F51B5（インディゴ）
アクセントカラー: #FFC107（アンバー）
背景色: #FFFFFF（ライト）/ #121212（ダーク）
テキスト: #212121（ライト）/ #FFFFFF（ダーク）
```

**タイポグラフィ**:
```
見出し: Noto Sans JP Bold, 20-28pt
本文: Noto Sans JP Regular, 14-16pt
キャプション: Noto Sans JP Regular, 12pt
```

**アイコン**: Material Icons / Feather Icons
