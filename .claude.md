# Music Like - プロジェクト固有指示書

アイドルファン向け音楽共有SNSアプリ「Music Like」の開発における、Claude Code専用の技術指示とコンテキスト情報です。

## プロジェクト概要

**コンセプト**: 好きな音楽を共有することがメインで、その後、音楽の趣味が合う人と自然に繋がれるSNS
**ターゲット**: 20-30代のアイドルファン（48グループ、ジャニーズ、ハロプロなど）
**アーキテクチャ**: React Native (Expo) + Supabase
**開発手法**: 2週間スプリント × 16週（Phase 1）

## 技術スタック規約

### フロントエンド
- **Framework**: React Native with Expo (managed workflow)
- **Language**: TypeScript (strict mode)
- **Navigation**: React Navigation v6
- **State Management**: React Context API + hooks (Redux不使用)
- **Styling**: StyleSheet (CSS-in-JS) - inline styles禁止
- **API Client**: Supabase JS Client v2
- **Form Validation**: React Hook Form + Zod

### バックエンド
- **Database**: Supabase PostgreSQL
- **Auth**: Supabase Auth (LINE/Apple/Google OAuth)
- **Realtime**: Supabase Realtime (DM、通知)
- **Functions**: Supabase Edge Functions (Deno)
- **Storage**: Supabase Storage (プロフィール画像）

### 開発ツール
- **Package Manager**: npm（yarnやpnpm不使用）
- **Linter**: ESLint (Airbnb config base)
- **Formatter**: Prettier (セミコロン有、シングルクォート)
- **Testing**: Jest + React Native Testing Library
- **Version Control**: Git with feature branch workflow

### Supabase データ操作
```typescript
// ✅ GOOD: Service pattern with error handling
import { supabase } from '../config/supabase';
import { Post, PostWithAuthor } from '../types/models';

export const postService = {
  async getHomeFeed(userId: string): Promise<PostWithAuthor[]> {
    const { data, error } = await supabase
      .from('posts')
      .select(`
        *,
        author:users!user_id (
          id,
          username,
          display_name,
          avatar_url
        )
      `)
      .eq('visibility', 'public')
      .order('created_at', { ascending: false })
      .limit(20);

    if (error) {
      console.error('Failed to fetch feed:', error);
      throw new Error('フィードの取得に失敗しました');
    }

    return data as PostWithAuthor[];
  },

  async createPost(post: Partial<Post>): Promise<Post> {
    const { data, error } = await supabase
      .from('posts')
      .insert(post)
      .select()
      .single();

    if (error) {
      console.error('Failed to create post:', error);
      throw new Error('投稿の作成に失敗しました');
    }

    return data as Post;
  },
};
```

### Row Level Security (RLS) パターン
```sql
-- ✅ GOOD: すべてのテーブルでRLSを有効化
ALTER TABLE posts ENABLE ROW LEVEL SECURITY;

-- 読み取りポリシー: visibility設定を尊重
CREATE POLICY "Posts are viewable based on visibility" ON posts
    FOR SELECT
    USING (
        visibility = 'public'
        OR user_id = auth.uid()
        OR (visibility = 'followers' AND user_id IN (
            SELECT following_id FROM follows WHERE follower_id = auth.uid()
        ))
    );

-- 書き込みポリシー: 自分の投稿のみ
CREATE POLICY "Users can insert their own posts" ON posts
    FOR INSERT
    WITH CHECK (user_id = auth.uid());

CREATE POLICY "Users can update their own posts" ON posts
    FOR UPDATE
    USING (user_id = auth.uid());

CREATE POLICY "Users can delete their own posts" ON posts
    FOR DELETE
    USING (user_id = auth.uid());
```

### Edge Functions パターン
```typescript
// ✅ GOOD: Deno Edge Function with error handling
import { serve } from 'https://deno.land/std@0.168.0/http/server.ts';
import { createClient } from 'https://esm.sh/@supabase/supabase-js@2';

serve(async (req) => {
  try {
    // CORS対応
    if (req.method === 'OPTIONS') {
      return new Response('ok', { headers: corsHeaders });
    }

    // リクエストボディ検証
    const { url } = await req.json();
    if (!url || typeof url !== 'string') {
      return new Response(
        JSON.stringify({ error: 'Invalid URL parameter' }),
        { status: 400, headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
      );
    }

    // ビジネスロジック
    const result = await fetchOGPMetadata(url);

    return new Response(
      JSON.stringify(result),
      { headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
    );
  } catch (error) {
    console.error('Function error:', error);
    return new Response(
      JSON.stringify({ error: error.message }),
      { status: 500, headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
    );
  }
});

const corsHeaders = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type',
};
```

// Phase 1: URL手動入力 + OGPプレビュー
// Spotify/Apple Music/YouTube Music URLをサポート
const SUPPORTED_MUSIC_SERVICES = [
  'open.spotify.com',
  'music.apple.com',
  'music.youtube.com',
];

async function createPlaylistPost(url: string, caption: string) {
  // 1. URL検証
  const isValidMusicUrl = SUPPORTED_MUSIC_SERVICES.some(service =>
    url.includes(service)
  );

  if (!isValidMusicUrl) {
    throw new Error('サポートされていない音楽サービスです');

  // 2. Edge FunctionでOGP取得

    body: { url },

  return await postService.createPost({
    user_id: userId,
    content_type: 'playlist',
    playlist_url: url,
    playlist_title: ogpData.title,
    playlist_thumbnail: ogpData.image,
    playlist_track_count: ogpData.trackCount,
    caption: caption,
  });
}

### 3. 同担拒否/歓迎機能
```typescript
// マッチング・検索時に必ずフィルタリング
async function findCompatibleUsers(currentUserId: string) {
  const { data: currentUserPrefs } = await supabase
    .from('user_idol_preferences')
    .select('*')
    .eq('user_id', currentUserId)
    .single();

  const { data: compatibleUsers } = await supabase
    .from('users')
    .select(`
      *,
      idol_prefs:user_idol_preferences (*)
    `)
    .neq('id', currentUserId)
    .filter('idol_prefs.allow_same_oshi', 'eq', true) // 相手が同担歓迎
    .filter('idol_prefs.oshi_group', 'eq', currentUserPrefs.oshi_group);

  // さらに、自分も同担歓迎の場合のみ推奨
  if (currentUserPrefs.allow_same_oshi) {
    return compatibleUsers;
  }

  return compatibleUsers.filter(user =>
    user.idol_prefs.oshi_member !== currentUserPrefs.oshi_member
  );
}
```

## セキュリティ要件

### 必須セキュリティ対策
1. **RLS必須**: すべてのテーブルでRow Level Securityを有効化
2. **認証チェック**: API呼び出し前に `auth.uid()` を検証
3. **入力検証**: Zodスキーマでユーザー入力を必ず検証
4. **XSS対策**: ユーザー生成コンテンツはサニタイズ
5. **CSRF対策**: Supabase Authのセッショントークン使用
6. **通報機能**: 不適切コンテンツの通報・ブロック機能実装

### 禁止事項
- ❌ 秘密鍵・APIキーをコードにハードコード
- ❌ SQLインジェクション可能なクエリ
- ❌ パスワード平文保存（Supabase Auth使用）
- ❌ RLS無効化
- ❌ 認証なしでの個人情報アクセス

## パフォーマンス最適化

### データベース最適化
```sql
-- ✅ GOOD: 頻繁に検索するカラムにインデックス
CREATE INDEX idx_posts_user_id ON posts(user_id);
CREATE INDEX idx_posts_created_at ON posts(created_at DESC);
CREATE INDEX idx_follows_follower_following ON follows(follower_id, following_id);

-- ✅ GOOD: 非正規化でカウント高速化
ALTER TABLE posts ADD COLUMN likes_count INTEGER DEFAULT 0;

CREATE OR REPLACE FUNCTION update_post_likes_count()
RETURNS TRIGGER AS $$
BEGIN
  IF TG_OP = 'INSERT' THEN
    UPDATE posts SET likes_count = likes_count + 1 WHERE id = NEW.post_id;
  ELSIF TG_OP = 'DELETE' THEN
    UPDATE posts SET likes_count = likes_count - 1 WHERE id = OLD.post_id;
  END IF;
  RETURN NULL;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER update_post_likes_count_trigger
AFTER INSERT OR DELETE ON post_likes
FOR EACH ROW EXECUTE FUNCTION update_post_likes_count();
```
