# アイドル好き向け音楽共有SNSアプリ

**好きな音楽を共有し、趣味が合う人と自然に繋がる音楽SNS**

## 🎯 プロジェクト概要

### コンセプト
音楽の趣味が合う人を「探す」のではなく、好きな音楽を「共有」することで自然に繋がるSNSアプリケーション。

- **メイン機能**: プレイリスト・今聴いてる曲の投稿と共有
- **サブ機能**: 音楽の趣味が合う人との繋がり
- **ターゲット**: アイドル好き（48グループ、ジャニーズ、ハロプロ等）

### アプリの特徴
- 📱 **SNS型**: マッチングアプリではなく、投稿・フィード中心
- 🎵 **音楽共有**: プレイリスト・今聴いてる曲を気軽に投稿
- 🤝 **自然な繋がり**: フォロー自由、マッチング不要
- 🛡️ **安全設計**: プライバシー保護、ブロック・通報機能

## 📱 主要機能

### Phase 1（MVP - 4ヶ月）

#### 認証
- LINE Login（日本市場最適化）
- Apple Sign-In（iOS必須）
- Google Sign-In（Android対応）

#### 音楽共有機能（コア）
- **プレイリスト投稿**: URL貼り付けで自動プレビュー生成
- **今聴いてる曲投稿**: 曲情報とコメント共有
- **テキスト投稿**: ライブレポート等
- **フィード**: タイムライン形式で投稿閲覧
- **エンゲージメント**: いいね・コメント・ブックマーク

#### ソーシャル機能
- **フォロー/フォロワー**: マッチング不要の自由なフォロー
- **ユーザー検索**: 推しグループ・ニックネームで検索
- **おすすめユーザー**: 同じ推しのファンを表示
- **ダイレクトメッセージ**: 1対1のチャット

#### 通知
- いいね・コメント・フォロー・DM通知

#### 安全機能
- ユーザーブロック
- 不適切コンテンツ通報
- プライバシー設定（公開/非公開）
- DM受信設定

### Phase 2（拡張 - 2ヶ月）
- Spotify/Apple Music API連携
- イベント情報共有
- グループ機能
- ハッシュタグトレンド

### Phase 3（収益化 - 1ヶ月）
- プレミアムプラン
- 広告表示
- 投げ銭機能

## 🛠️ 技術スタック

### フロントエンド
- **フレームワーク**: React Native (Expo)
- **状態管理**: Redux Toolkit
- **UI コンポーネント**: NativeBase / React Native Elements

- **BaaS**: Supabase

- **音楽サービス**: Spotify, Apple Music, YouTube Music, LINE MUSIC
- **プッシュ通知**: Expo Notifications

- **監視**: Sentry

- **バージョン管理**: Git
- **パッケージ管理**: npm / yarn
- **コード品質**: ESLint, Prettier
- **テスト**: Jest, React Native Testing Library

## 🔐 セキュリティ・プライバシー

### 実装予定のセキュリティ機能
- **データ暗号化**: TLS 1.3（通信）、AES-256（保存）
- **認証**: OAuth 2.0（LINE/Apple/Google）
- **アクセス制御**: Row Level Security（Supabase）
- **コンテンツ審査**: 不適切言語フィルター、画像検閲
- **監査ログ**: ユーザー行動の記録

### プライバシー保護
- **最小限の情報収集**: 必要最小限の個人情報のみ
- **データ削除権**: ユーザーはいつでもアカウント削除可能
- **透明性**: プライバシーポリシーの明示
